# Opportunity Board

A micro-version of an Opportunity Search Board built with Next.js and Material UI.

## How to run locally

1. Clone the repository
2. Install dependencies:
3. Run the development server:
4. Open http://localhost:3000 in your browser

## UX Decisions

I chose to enable real-time search and filter which means that the card grid updates immediately once the user enters any letter without requiring them to press any button. I think this option makes it faster and easier for the user to reach what they need.
